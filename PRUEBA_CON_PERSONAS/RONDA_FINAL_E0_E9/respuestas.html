Importar respuestas

Pega el texto de envío del teléfono o elige el archivo JSON. Se valida el banco y se fusiona sin duplicar respuestas; los datos se quedan en este navegador.

Exportar datos

Los CSV incluyen BOM UTF-8 para abrirlos en Excel. Las exportaciones respetan los filtros seleccionados.

Borrar respuestas

Esta acción está disponible solo aquí. Antes de borrar, puedes exportar los datos. Escribe BORRAR para confirmar; se borrarán las respuestas, las sesiones archivadas y la sesión activa.

El navegador pedirá una segunda confirmación antes de borrar.
